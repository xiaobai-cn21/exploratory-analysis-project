# 教育公平性探索性分析方案

> **目标聚焦**：仅基于已完成基础清洗（脏数据、重复值已处理）的 `AP_IB_Assessment_2024` 评估数据表，对“教育公平性”核心研究问题开展探索性分析与可视化，揭示不同人群、地区、学校层级在 AP/IB 参与与成绩上的差异。

---

## 1. 分析前提与数据理解

- **数据范围**：纽约州 2023-2024 学年 AP/IB 评估数据，包含 5 层聚合（全州、N/RC、县、学区、学校）。
- **字段重点**：人口统计分组（`SUBGROUP_CODE/NAME`）、地理字段（`aggregation_index`, `NRC_CODE`, `COUNTY_CODE`, `LEA_BEDS`, `INST_ID`）、课程属性（`APIB_IND`, `SUBJECT_AREA`, `ITEM_DESC`）以及绩效计数（`tested_student_cnt`, `proficient_student_cnt`, `level1-7_cnt`）。
- **数据质量假设**：当前数据已去除脏数据与重复行，但仍需在探索阶段校验逻辑一致性（如等级计数之和、抑制值“-”等），并针对隐私抑制与条件缺失做解释。
- **研究聚焦**：核心问题一——教育公平性：不同社会经济、族裔、性别等群体在 AP/IB 参与度与达标率上的差异；不同地区（N/RC、县、学区、学校）的资源配置与成果差异。

---

## 2. 总体分析框架

1. **指标体系构建**
   - 参与面：`tested_student_cnt`、参与占比（按聚合层级、人口分组、学科）。
   - 成果面：`proficient_student_cnt`、`proficiency_rate`（按 AP/IB 定义）、高分率、等级分布。
   - 公平性面：群体差值（Gap）、比率、基尼/泰尔指数（选做）；地区资源负担（N/RC） vs 表现。
2. **分层分析顺序**
   - **宏观**：全州总体、AP/IB 对比。
   - **人口分组**：性别、族裔、经济状况、ELL、残障等 24 个子群。
   - **地理层级**：N/RC → 县 → 学区 → 学校，结合 NYC vs 非 NYC。
   - **学科/课程**：`SUBJECT_AREA`、`ITEM_DESC` 热度与表现。
3. **可视化策略**
   - 面积/条形展示参与规模
   - 误差线/箱线展示分布
   - 热力/地图呈现地区差异
   - 堆叠/瀑布展示等级结构
   - 点图/象限突出公平性差距

---

## 3. 数据准备步骤

1. **载入与基础清洗**
   - 读取 `assessment_clean.parquet/csv`（假设清洗后存档），保留核心字段。
   - 统一字段大小写（`GRADE_LEVEL`→`grade_level` 等），确保数值字段转为数值型（将 `'-'` 替换为 NaN 并创建 `is_suppressed` 标记）。
2. **派生指标**
   - `proficiency_cnt_calc`：AP = `level3_cnt+level4_cnt+level5_cnt`；IB = `level4_cnt+level5_cnt+level6_cnt+level7_cnt`。
   - `proficiency_rate = proficiency_cnt_calc / tested_student_cnt`（仅当 `tested_student_cnt >= 5` 且无抑制）。
   
   - `high_score_rate`、`participation_share`（按聚合层级）。
   - 差异指标：按基准群体（如 “All Students” 或州平均）计算的 Gap、比率。
3. **分组映射**
   - 建立 `SUBGROUP_CODE`、`aggregation_index`、`NRC_CODE` 解读字典，便于图例与文本说明。
4. **数据切片**
   - 构建多粒度 DataFrame：州级（index=0）、N/RC（1）、县（2）、学区（3）、学校（4）。
   - 预计算各粒度下的关键统计（均值、中位数、分位数、标准差），加速可视化。

### 4.2 人口统计公平性分析

1. **参与公平性**
   - 指标：群体参与率 `participation_rate = tested_student_cnt / 全州同层级总人数（使用 All Students 作为分母）`
   - 图表：24 子群的分面条形图；Highlight 关键群体（性别、族裔、经济、ELL、残障）。
2. **达标公平性**
   - 指标：`proficiency_rate`、`high_score_rate`
   - 图表：箱线 + 折线（AP/IB 分面），突出均值差异与分布范围。
3. **公平性差距（Gap）**
   - 指标：`gap_vs_all = group_rate - all_students_rate`
   - 图表：瀑布图或象限散点（X=参与率差、Y=达标率差），识别双重劣势群体。
4. **交互式 Drill-down（可选）**
   - 使用 Plotly/Altair 实现 hover 提示，显示具体分组、层级、样本数。

> **前端映射**：创建 “人口统计公平性” 章节，`chart-grid` 共 4-6 张卡片：参与率对比、达标率箱线、Gap 象限、可交互 Drill-down。为便于交互，可在每张卡片右上角放置 `.chart-filter`（下拉选 AP/IB，或切换层级），CSS 沿用导航按钮样式。

### 4.3 地理维度公平性

1. **N/RC 分类对比**
   - 指标：平均参与率、达标率、抑制率、课程覆盖度（以 `ITEM_DESC` 数量近似）。
   - 图表：雷达图（表现 vs 资源）、分组箱线（展示离散程度）。
2. **县/学区层级**
   - 结合 `COUNTY_CODE`, `LEA_BEDS`，计算 Top/Bottom 表现榜单。
   - 图表：分位数箱线、排名条形、散点（参与 vs 达标）。
3. **地理热力图**
   - 数据：县级聚合 `proficiency_rate`、`gap_经济困难` 等。
   - 工具：`geopandas + folium` 或 `plotly.choropleth_mapbox`。
   - 输出：纽约州县级/学区热力，突出资源与表现不均。

> **前端映射**：章节标题 “地理视角 | N/RC-县-学区”。布局：左侧使用 2 张图（N/RC 雷达、县级箱线），右侧上下堆叠地图（Plotly choropleth）与 Top/Bottom 榜单。地图容器建议全宽单列（设置 `chart-grid` 的 `grid-column: 1 / -1`）。

### 4.4 学科与课程维度

1. **学科热度与表现**
   - 聚合 `SUBJECT_AREA`：统计参加人数、达标率、抑制率。
   - 图表：热力矩阵（行=学科，列=群体/地区），或气泡图（大小=人数、颜色=达标率）。
2. **课程粒度（ITEM_DESC）**
   - 选取 Top 15 参与课程，比较 AP/IB 表现差异。
   - 图表：分面条形/箱线，配合注释（如 STEM vs Humanities）。

> **前端映射**：章节标题 “学科与课程表现”。`chart-grid` 包含：学科热力（全宽）、Top 15 课程条形、STEM vs Humanities 对比等。图例采用 `.chart-legend`（水平圆点 + 文本），颜色遵循主辅色。

### 4.5 等级结构与资源匹配

1. **等级分布一致性**
   - 校验 `tested_student_cnt` 与 `level1-7_cnt` 之和；说明异常占比（若存在）。
   - 图表：堆叠百分比条形（不同层级/群体的等级构成）。
2. **资源-结果象限**
   - 构建 `resource_proxy`（如 NRC 逆序、NYC 指示） vs `proficiency_rate`。
   - 图表：散点象限图（资源高/低 × 表现高/低），寻找“高需求低表现”区域。

> **前端映射**：章节标题 “等级结构与资源匹配”。在 `chart-card` 内加入 `metric-pills`（3-4 个圆角指标展示资源指标），散点象限图使用背景栅格线，与 CSS 主色匹配。

## 5. 执行步骤指南（Jupyter Notebook 结构）

1. **Notebook 设置**
   - `01_data_overview.ipynb`：数据读取、字段说明、基本统计。
   - `02_fairness_eda.ipynb`：人口、地理、学科等分面分析。
   - `03_geo_visualization.ipynb`：地图生成。
   - `04_dashboard_prototype.ipynb`（可选）：整合交互图表。

2. **代码骨架示例**

```python
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt
import plotly.express as px

df = pd.read_parquet("cleaned_data/AP_IB_Assessment_2024_clean.parquet")

# 抑制标记与数值化
score_cols = [c for c in df.columns if c.endswith("_cnt")]
for col in score_cols:
    df[col] = pd.to_numeric(df[col].replace('-', np.nan))
df["is_suppressed"] = df["proficient_student_cnt"].isna()

# 达标率示例
def calc_proficiency(row):
    if row["APIB_IND"] == "AP":
        return row["level3_cnt"] + row["level4_cnt"] + row["level5_cnt"]
    return row["level4_cnt"] + row["level5_cnt"] + row["level6_cnt"] + row["level7_cnt"]

df["proficiency_cnt_calc"] = df.apply(calc_proficiency, axis=1)
df["proficiency_rate"] = np.where(
    (df["tested_student_cnt"] >= 5) & (~df["proficiency_cnt_calc"].isna()),
    df["proficiency_cnt_calc"] / df["tested_student_cnt"],
    np.nan
)
```

3. **可视化模板**
   - `sns.catplot` 分面条形展示人口差异。
   - `sns.boxplot` / `sns.violinplot` 比较达标率分布。
   - `px.choropleth` 渲染县级公平性指数。
   - `px.scatter` + `trendline` 展示资源 vs 表现关系。

## 7. 风险与控制

- **抑制数据**：在计算率值时过滤 `tested_student_cnt < 5`，并显式标注抑制区域；必要时采用贝叶斯平滑或聚合更高层级。
- **样本量不均**：为每个群体/地区提供 `tested_student_cnt` 注释，避免误判。
- **多重比较**：对大量群体对比提供置信区间或显著性检验（如 ANOVA、Kruskal-Wallis）结果。
- **可重复性**：Notebook 中封装图表函数，保存随机种子，记录依赖版本。
