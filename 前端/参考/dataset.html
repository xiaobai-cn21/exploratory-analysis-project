Dataset Overview

数据集非常全面，包含了大量与AP/IB课程和评估相关的信息。我们下载了完整的 Advanced Placement and International Baccalaureate Course and Assessment Data 2024数据集， 来自纽约州教育部（NYSED）官方数据门户。

数据表概览

📚 课程表 (AP_IB_Course_2024)

记录数：415,765 行

字段数：21 个

主要内容：AP和IB课程注册数据

包含学生注册AP/IB课程的信息，涵盖不同聚合级别（全州、县、学区、学校）、 人口统计分组、课程详情等。

📊 评估表 (AP_IB_Assessment_2024)

记录数：467,535 行

字段数：29 个

主要内容：AP和IB评估成绩数据

包含学生参加AP/IB评估的参与和成绩信息，包括各等级成绩分布、 达标学生数等详细评估数据。

数据字段详情

数值型字段

字段名 类型 最小值 最大值 缺失值 描述
REPORT_SCHOOL_YEAR VARCHAR - - 0% 数据收集学年（固定值：2023-24）
aggregation_index VARCHAR 0 4 0% 聚合级别索引（0=全州,1=N/RC,2=县,3=学区,4=学校）
STUDENT_COUNT Number 0 可变 0% 注册该课程的学生数
TESTED_STUDENT_CNT Number 0 可变 0% 参加评估的学生数
NRC_CODE Number 1 9 0% 需求资源能力代码（1=低需求,9=高需求）
NYC_IND Text 0 1 0% 是否在纽约市（0=否,1=是）

分类型字段

字段名 唯一值数 最常见值 缺失率 描述
aggregation_type 5 State Total 0% 聚合类型（全州/N/RC/县/学区/学校）
COUNTY_NAME 62 New York 0% 县名称（纽约州共62个县）
SUBGROUP_NAME 20+ All Students 0% 人口统计分组名称（经济困难、种族、性别等）
APIB_IND 2 AP 0% 课程类型（AP或IB）
SUBJECT_AREA 10+ Mathematics 0% 学科领域（数学、科学、语言等）
COURSE_DESC 100+ AP Calculus AB 0% 课程全名
ITEM_DESC 100+ AP Calculus AB 0% 评估全名（仅评估表）

成绩字段（评估表独有）

字段名 类型 说明
PROFICIENT_STUDENT_CNT Text 达标学生数（AP≥3分，IB≥4分），可能为'-'（隐私保护）
LEVEL1_CNT ~ LEVEL7_CNT Text 各等级成绩学生数，AP使用1-5级，IB使用1-7级，可能为'-'

⚠️ 重要提示

  • 为确保学生隐私，少于5名学生参加考试的群体数据被抑制为'-'
  • 被抑制的数据需要使用Val()函数转换为数值类型进行计算
  • 课程数据不受抑制限制
